# Learn SQL: beginner to advanced (SQL Server / T-SQL)

An end-to-end, self-paced SQL course as plain HTML (no build step, no internet needed).

## Open it

Double-click `index.html`. The visuals and navigation work straight from the file system.

## Contents

- `index.html`: course home, sample database preview, course map, practice plan
- `pages/01-...34-*.html`: 34 topics in the order of the video chapters (6 beginner, 15 intermediate, 13 advanced)
- `sql/00_setup.sql`: creates the `MyDatabase` sample database (Customers, Employees, Products, Orders); safe to re-run
- `assets/`: shared styles and the course engine (SQL highlighter, step-by-step visualiser, progress tracking)

## Phase 2 (next)

`practice/`: 120 questions with their own datasets, your answers (`Qnnn.sql`) and my reviews (`Qnnn.review.md`), pushed to Git.
