Setup your environment

Install SQL Server and a query tool, create the sample database, and run your first query.

After this topic you will have a working SQL Server, a client connected to it, and the MyDatabase sample data loaded.

What you need

PieceWhat it isGet it
SQL Server (the engine)The server process that stores data and runs queriesFree Developer or Express edition from Microsoft
SSMS (the client)SQL Server Management Studio: a Windows app with a query editor and object explorerFree from Microsoft. Alternative: Azure Data Studio or the VS Code MSSQL extension
Two parts, alwaysThe engine and the client are separate programs. SSMS is only a window; the data lives in the server.

Option A: install on Windows (simple)

  1. Download SQL Server Developer (or Express). Run the installer, choose Basic.
  2. Note the connection string it shows at the end (usually localhost or localhost\SQLEXPRESS).
  3. Install SSMS.
  4. Open SSMS, Server name: localhost (or .\SQLEXPRESS), Authentication: Windows Authentication, tick Trust server certificate, click Connect.

Option B: Docker (you already use Docker)

docker run -e "ACCEPT_EULA=Y" -e "MSSQL_SA_PASSWORD=Str0ng!Passw0rd" -p 1433:1433 --name sql2022 -d mcr.microsoft.com/mssql/server:2022-latest

Then connect from SSMS or Azure Data Studio with server localhost,1433, login sa and that password, trust server certificate on. Change the password to your own. Do not reuse a real one; it is only a local learning box.

Load the sample database

  1. In SSMS click New Query (Ctrl+N).
  2. Open sql/00_setup.sql from this folder (File > Open > File), or paste its contents.
  3. Press F5 (or Execute). Wait for the last grid: Setup complete, 5, 5, 5, 10.
  4. In Object Explorer press refresh on Databases. You will see MyDatabase.

Your first queries

USE MyDatabase;          -- choose which database the next statements run in
GO                       -- tells SSMS: send the batch above to the server now

SELECT * FROM Customers; -- all five customers
SELECT * FROM Orders;    -- all ten orders
  • USE switches the current database. You can also pick it in the toolbar dropdown.
  • GO is not SQL; it is a batch separator understood by SSMS and sqlcmd.
  • Highlight one statement and press F5 to run only that selection.

Common problems
  • Cannot connect: check the SQL Server service is running (Services app, "SQL Server (MSSQLSERVER)").
  • Certificate error: tick Trust server certificate.
  • Invalid object name 'Customers': you are in master. Run USE MyDatabase;.
Try it

Run SELECT COUNT(*) FROM Orders; and SELECT @@VERSION;. The first should return 10; the second shows your server version.
