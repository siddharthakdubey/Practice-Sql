Introduction to SQL

What a database is, what SQL is, and what actually happens between pressing F5 and seeing rows.

After this topic you will explain: database vs DBMS vs SQL, tables/rows/columns/keys, the five SQL command families (DDL, DML, DQL, DCL, TCL), and the client-server path of a query.

DialectsSQL is a standard (ANSI), but each product adds its own flavour. SQL Server's is T-SQL (TOP, GETDATE(), [brackets]). The ideas transfer, the small syntax differs. Where it matters, this course names the difference.

Relational model: tables, rows, columns, keys

  • Table: one kind of thing (customers).
  • Column (field): one attribute with a data type (Score is INT).
  • Row (record): one instance (Kevin).
  • Primary key (orange column): uniquely identifies a row. Never NULL, never repeated.
  • Foreign key: a column that refers to another table's primary key. Orders.ProductID refers to Products.ProductID. This is how tables are linked, and what joins use.
  • NULL: "unknown / missing". Mary has no LastName, Anna has no Score. NULL is not zero and not an empty string.

What happens when you run a query

The optimizer is the clever part: it picks the cheapest way to get your answer (which index, which join algorithm, which order). You see its choice in the execution plan (topic 31).

Why SQL, and why it lasts

  • Declarative: you state the result, the engine does the work.
  • Same skill across SQL Server, PostgreSQL, Oracle, MySQL, Snowflake, BigQuery, Spark SQL.
  • Used by developers, analysts, data engineers, testers and auditors alike.
  • Over 50 years old and still the main way to query business data.

Your first query

SELECT *
FROM Customers;

Read it aloud: "select all columns from the Customers table". The * means every column. The semicolon ends the statement (optional in T-SQL, but a good habit and required before some keywords).

Try it

Classify each as DDL, DML, DQL, DCL or TCL: DROP TABLE Orders, UPDATE Customers SET Score = 0, COMMIT, GRANT SELECT ON Orders TO analyst. (DDL, DML, TCL, DCL.)
