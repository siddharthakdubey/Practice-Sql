Numeric functions

Rounding, absolute values, powers, remainders, and the integer-division trap.

After this topic you will use ROUND, CEILING, FLOOR, ABS, SIGN, POWER, SQRT, the % operator and RAND, and avoid integer-division and floating-point surprises.

Arithmetic operators

OperatorMeaningExampleResult
+ - *add, subtract, multiplyQuantity * 10
/divide7 / 2 and 7 / 2.03 (both INT: integer division!) and 3.500000
%remainder (modulo)7 % 31 (use for even/odd: n % 2 = 0)
Integer divisionSales / Quantity where both are INT drops the decimals. Multiply by 1.0 or CAST one side to DECIMAL first: CAST(Sales AS DECIMAL(10,2)) / Quantity. Dividing by zero raises an error: guard with NULLIF(x, 0) (topic 15).

ROUND, CEILING, FLOOR

SELECT ROUND(3.516, 2)    -- 3.520     keep 2 decimals
     , ROUND(3.516, 0)    -- 4.000     to a whole number (scale stays, shown as 4.000)
     , ROUND(1234.5, -2)  -- 1200.0    negative length rounds to hundreds
     , CEILING(3.2)       -- 4         always up
     , FLOOR(3.8)         -- 3         always down
     , ROUND(3.8, 0, 1)   -- 3.0       third argument 1 = truncate instead of round
;

ABS, SIGN

SELECT ABS(-45.5)     -- 45.5   distance from zero
     , SIGN(-45.5)    -- -1     (-1, 0 or 1)
     , SIGN(0)        -- 0
;
-- how far is each salary from 70000, regardless of direction
SELECT FirstName, Salary, ABS(Salary - 70000) AS Gap FROM Employees;
FirstName | Salary | Gap Frank | 55000 | 15000 Kevin | 65000 | 5000 Mary | 75000 | 5000 Michael | 90000 | 20000 Carol | 55000 | 15000

POWER, SQRT, EXP, LOG, PI

SELECT POWER(2, 10)      -- 1024
     , SQUARE(7)         -- 49
     , SQRT(144)         -- 12
     , LOG(100, 10)      -- 2   (log base 10)
     , PI()              -- 3.14159265358979
;
-- compound interest on 100000 at 8% for 5 years
SELECT CAST(100000 * POWER(1 + 0.08, 5) AS DECIMAL(12,2)) AS FutureValue;   -- 146932.81

RAND: random numbers

SELECT RAND();                          -- decimal between 0 and 1, same value for every row of one query!
SELECT RAND(CHECKSUM(NEWID()));         -- a different random value per row
SELECT TOP 2 * FROM Customers ORDER BY NEWID();   -- 2 random rows (sampling)

Exact vs approximate numbers (important for money)

SELECT CAST(0.1 AS FLOAT) + CAST(0.2 AS FLOAT);          -- 0.30000000000000004 in binary maths
SELECT CAST(0.1 AS DECIMAL(5,2)) + CAST(0.2 AS DECIMAL(5,2));   -- 0.30 exactly

FLOAT stores binary approximations; DECIMAL(p,s) stores exact decimal digits. For money, rates and anything audited: DECIMAL. For science and statistics, FLOAT is fine.

Where this shows up

  • Price with tax: ROUND(Sales * 1.18, 2).
  • Percent of total: 100.0 * Sales / SUM(Sales) OVER () (topic 19; note the 100.0).
  • Bucketing: FLOOR(Score / 100) * 100 gives 300, 500, 700, 900 bands.
  • Even/odd split, pagination maths (CEILING(1.0 * total / pagesize) = number of pages).
